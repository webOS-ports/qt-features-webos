qt-features-webos
=================

Summary
-------
Qt configuration features and tools for webOS.

Description
-----------
This package contains Qt configuration features(prf), tools and keycode definitions for webOS.

Tests
-----
`tests/` holds the unit tests (gtest), the qmake feature tests and the
hardening scripts; `tests/README.md` describes them. They are a standalone
CMake project and not part of the qmake build.
